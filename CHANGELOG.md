## [0.6.0] - 2026-10-05

### Added

- Add the recorded Mars signal walkthrough as the default demonstration, including its source captures, calculations, numerical checks, and documented limitations.
- Add declared per-output value lineage, authored-stage navigation, and portable React trace controls without changing graphs that omit lineage annotations.
- Publish Orrery as `@axiom-foundation/orrery` and manage releases with Towncrier fragments, reproducible npm archives, provenance, checksum verification, annotated version tags, and matching GitHub releases.

### Changed

- Rank exact record labels and identifiers ahead of matches found only in stored payload fields while preserving access to every result.
